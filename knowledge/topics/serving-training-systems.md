# 服务、训练与 RL 系统

服务系统组织动态请求，训练系统组织可重复的大规模矩阵计算，RL 系统则在生成、评分和参数更新之间循环。三者共享硬件，却不能用同一个吞吐指标概括。

## 1. 推理服务的基本组织

典型链路包括：

请求接入 -> 分词与前缀匹配 -> 调度 -> Prefill -> KV/状态管理 -> 连续 Decode -> 流式输出 -> 释放或保留会话状态

连续批处理在 token 步粒度加入新请求、移除完成请求，比整请求静态 batch 更适合不同输出长度。但调度器必须同时考虑：

- Prefill 大矩阵与 decode 小矩阵的资源偏好；
- 新请求 TTFT 与在途请求 TPOT；
- KV 块是否足够以及碎片；
- 长请求是否阻塞短请求；
- 优先级、抢占和恢复成本；
- 前缀命中与数据局部性。

Chunked Prefill 将长前缀分块，与 decode 混合执行，可降低长输入对 token 间隔的冲击；但块大小影响权重复用和调度开销，需要实测。

## 2. PD 分离与 KV 传输

Prefill/Decode 分离让两类阶段使用不同并行和资源配置，适合长输入、资源异构或需要独立扩缩容的场景。新增成本包括：

- KV 从 Prefill 节点传到 Decode 节点；
- 传输与首 token 的关键路径重叠；
- 两层排队和容量配比；
- 失败重试与状态一致性；
- 网络、CPU 和序列化开销。

PD 分离不是天然更低延迟。只有节省的资源或改善的隔离大于传输与调度成本时才成立。

## 3. 训练计算与状态

线性层训练除前向外还需输入梯度和权重梯度，矩阵计算常粗略为前向三倍，因此常用：

$$F_{train}\approx6ND$$

$N$ 为参与训练的参数量，$D$ 为训练 token 数。它忽略或简化 Attention、重计算、Embedding、通信、流水线空泡和低效 kernel，只适合一阶容量估算。

全参数 AdamW 常见状态包括 BF16 权重与梯度、FP32 master weight 和一阶/二阶动量。书稿以每参数约 18 字节粗算 Qwen3-8B 的优化相关状态，尚未包含激活、临时缓冲、通信 bucket 和碎片。

ZeRO/FSDP 分片降低单卡状态，却增加参数、梯度或优化器状态的通信。节省显存与网络开销必须一起计算。

## 4. RL 是多个阶段组成的周期

生成阶段通常自回归、状态密集；评分可能调用奖励模型、规则、验证器或环境；更新阶段接近训练。若样本保留比例为 $a$，为了得到 $n_{keep}$ 条有效样本：

$$n_{generate}\approx\frac{n_{keep}}{a}$$

低保留率会放大 rollout 成本。若每轮生成 $n$ 条、生成和评分平均计算量为 $f_g$ 和 $f_r$，更新计算量为 $F_u$：

$$F_{cycle}(n)=n(f_g+f_r)+F_u$$

但真实时间还取决于阶段是否重叠、Actor/Learner 是否同卡、权重同步、环境速度和样本到达是否均衡。

## 5. RL 系统调度

共卡部署节省权重副本，却要在生成和训练之间切换，可能产生：

- KV 与训练激活争抢显存；
- kernel/通信模式切换；
- 权重版本同步；
- 利用率互相干扰。

分离部署可独立扩展 rollout 与 learner，但需要参数广播、样本队列和版本控制。若 learner 更新快而 rollout 慢，训练资源等待；反之样本堆积、策略变旧。

因此要看全周期吞吐、有效样本率、样本陈旧度和最终成功率，而不是只看 rollout token/s 或训练 MFU。

## 6. 生命周期成本

计算最优 Scaling Law 关注训练预算下如何分配参数与 token，并不自动等于产品全生命周期最优。较大模型可能训练较少却长期推理更贵；较小模型训练更充分，前期成本更高但后续每次服务便宜。

若两种方案一次性成本差为 $\Delta C_0$，单位请求成本差为 $\Delta c$，回本请求量可写为：

$$Q_*=\frac{\Delta C_0}{\Delta c}$$

还要加入质量、成功率、延迟、上下文能力、硬件可得性和研发周期。若小模型质量不足导致更多重试，其名义 token 成本优势可能消失。

## 7. 统一评估框架

无论服务、训练还是 RL，都可按五层拆解：

1. 任务：成功样本、SLO 或训练目标；
2. 工作：token、样本、矩阵计算与通信；
3. 状态：权重、KV、激活、优化器和样本队列；
4. 时间：排队、计算、等待、同步和失败重试；
5. 成本：硬件时长、能耗、工具和全生命周期摊销。

这样才能把“某 kernel 更快”与“整个系统更值得”区分开。
